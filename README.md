## 📖 Overview

Legend-HexToText is a cyber-themed Python toolkit designed for inspecting, decoding and analyzing firmware and binary files used in industrial automation and embedded systems.

It was developed to assist with reverse engineering, firmware inspection, PLC investigations, configuration analysis and text extraction from Intel HEX and binary files.

The application provides a graphical interface for engineers, developers and researchers working with industrial control systems.

---

## ✨ Features

- 🔍 Automatic file type detection
- 📄 Intel HEX decoding
- 🔤 ASCII string extraction
- 💾 Binary file inspection
- 🏭 PLC/HMI keyword scanner
- 🏷 Version & build information finder
- 📦 Save decoded firmware
- 📑 Export analysis reports
- 🔄 Compare two firmware files
- 🔎 Full text search
- 🖥 Cyber-themed graphical interface

---

## Supported File Types

- Intel HEX (*.hex)
- Raw Binary (*.bin)
- PLC firmware
- HMI exports
- TwinCAT exports
- Siemens exports
- Embedded firmware images

## Installation

Clone the repository

```bash
git clone https://github.com/DK4Never/Legend-HexToText.git

cd Legend-HexToText
```

Run

```bash
chmod +x CyberHexTool.py

python3 CyberHexTool.py
```
