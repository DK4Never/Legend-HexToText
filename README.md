# Legend Cyber Hex / PLC Firmware Inspector

Cyber-themed local Python UI for inspecting:

- Intel HEX firmware
- Raw binary files
- PLC/HMI artifacts
- TwinCAT/Siemens config exports
- Embedded firmware files

## Features

- File type auto-detection
- Intel HEX decoding
- ASCII string extraction
- PLC keyword scanner
- Version/build finder
- Hex viewer
- Save decoded binary
- Export full report
- Compare two files
- Search output panel

## Install

```bash
cd ~/Legend/HexTOtext
chmod +x CyberHexTool.py
python3 CyberHexTool.py
